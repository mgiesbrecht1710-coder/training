# Training

Gym-App fürs Handy: Plan mit Geräte-Bildern, Training Schritt für Schritt (Sätze, Wdh., kg, Pausen-Timer), Fortschritts-Fotos und Monats-Review.

Daten: Supabase (Tabellen `gym_*`, privater Foto-Speicher `gym-photos`). Wach gehalten über den Workflow im Fahrtenbuch-Repo (gleiches Supabase-Projekt).
